# Contributing to AI-Net

Welcome to contribute to the AI-Net project!

**Repository**: https://github.com/joezhouai/ainet

---

## 🚀 Quick Start

### 1. Fork the Repository

Click the Fork button on GitHub.

### 2. Clone the Repository

```bash
git clone https://github.com/joezhouai/ainet.git
cd ainet
```

### 3. Create a Branch

```bash
git checkout -b feature/your-feature-name
```

### 4. Commit Changes

```bash
git add .
git commit -m "feat: add your feature"
git push origin feature/your-feature-name
```

### 5. Create a Pull Request

Create a PR on GitHub.

---

## 📝 Commit Message Convention

We follow [Conventional Commits](https://www.conventionalcommits.org/):

| Type | Description | Example |
|------|-------------|---------|
| `feat:` | New feature | `feat: add message validation` |
| `fix:` | Bug fix | `fix: fix state machine bug` |
| `docs:` | Documentation update | `docs: update README` |
| `refactor:` | Refactoring | `refactor: optimize parser logic` |

---

## 📁 Project Files
